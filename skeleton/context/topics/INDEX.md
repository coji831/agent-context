# Topic register

> **A register, not a rule book.** The rules live in [`../README.md`](../README.md); this file only
> says which topics exist, what each covers, and when it was last verified. It changes whenever a
> topic opens, drains or is renamed - which is exactly why it is not inside the contract README.
>
> Checked in both directions: a folder with no row is a finding, and a row whose first cell is neither a
> folder under `context/topics/` nor a folder under the configured `archive_dir` is a finding. A **drained** row
> names the archive folder instead - `| \`context/archive/<topic>/\` | drained - <what it covered> | <date> |` -
> and its last column is the day the receipt was checked. For a live row, the last column must equal the
> `Verified:` date in that topic's own `README.md`.
