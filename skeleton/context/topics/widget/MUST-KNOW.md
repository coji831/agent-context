# MUST-KNOW - widget

brief: the constraints that hold for this area only

> **Example file, delete it on adoption.** A topic gets a `MUST-KNOW.md` only when a constraint here would
> cost a stranger real time - this one is shipped so the second read step is visible. Two conditions, both
> required: it applies to **this area** and it has already cost somebody real time.
>
> Pruned, never appended, and it is the **second** thing read when the topic is opened, before `HANDOFF.md`.
> A rule that applies to *every* topic belongs in `context/MUST-KNOW.md`, not here.

1. **Never compare a rate measured on the demo rig with one measured anywhere else.** The rig is throttled
   unless proven otherwise, so a cross-rig comparison measures the fixtures, not the widget. *(example)*
2. **A number nobody measured is `[absent]` in the leaf - never zero, never a remembered figure.** *(example)*

Add a rule only after the mistake has happened twice, or once at a cost you would not pay again.
