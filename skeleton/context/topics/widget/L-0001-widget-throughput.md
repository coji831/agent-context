# L-0001 - widget throughput

One leaf, so the pattern is visible end to end. Replace it.

A leaf is a **conclusion with its evidence** - not a note, not a log. What was asked, how it was
measured, what follows, and the option that was rejected. Mark every claim: `[read]` for something you
opened, `[ran]` for a command's real output, `[inferred]` for reasoning from those, `[absent]` for a value
nobody measured.

## What was measured

The question, the method, and the numbers.

## Verdict

What follows from it, in one paragraph.

## Rejected

The option that was ruled out, and the one thing that made it unacceptable.
