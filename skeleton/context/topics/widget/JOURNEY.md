# JOURNEY

> Append-only. One entry per turn: what happened, and what it produced. Appended by the agent while it
> works, by hand: the tool moves no file, so nothing writes an entry for you. Nothing loads it, nothing
> summarises it, and no rule requires it to exist, because nothing is obliged to read it.
>
> **Write the process, not only the result.** An entry records the route taken, what was considered and set
> aside, and the `produced:` id it ended at. It may hold reasoning; it is never corrected, so it is a record
> of what was thought at that moment, never a conclusion anyone cites. The conclusion belongs in the leaf.
>
> **The entry below is an example written by this scaffold, not history.** Delete this topic when you
> adopt (scaffold README, section 5) and your first real entry is `J-0001`.
