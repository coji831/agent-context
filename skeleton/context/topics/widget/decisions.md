# decisions - the choices this topic made

brief: the choices this topic made, and what each ruled out

> **Example file, delete it on adoption, and create one of these with the topic's first real choice.** The
> record of what was *decided*, not a plan and not a log. Opened only when a choice is being relitigated -
> never at the topic's trigger, and never at start.
>
> Each row is an id `D-####` that a `JOURNEY` entry can cite, one sentence of decision in the present
> tense, the measurement or failing case that decided it, and what was ruled out *and why*. No cap,
> deliberately: the column a later session needs most is **Ruled out**, because it is what stops the same
> argument starting twice.
