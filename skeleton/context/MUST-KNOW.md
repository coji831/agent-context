# MUST-KNOW - the constraints that apply to every topic

> **Two conditions, both required.** A rule is here only when it applies to **every** topic *and* it
> has already cost real time. Ten is the cap; the first line is the one that costs most when broken.
> A constraint about one area belongs in that topic's `MUST-KNOW.md` - it loads with the topic, not
> with the repo.
>
> Pruned, never indexed. A rule that has never prevented anything is a reader's tax.

1. **A handoff is rewritten, never appended.** A snapshot that has to be appended to is a journal, and
   a journal is what a handoff replaces.
2. **Never cite a path you have not opened in this session.** A confident wrong pointer is worse than no
   memory: it sends the next session somewhere plausible and empty.
3. **A conclusion goes in a leaf; the reasoning that reached it does not belong in a snapshot or an
   index.** One line of fact, or one leaf with its evidence - never half of each in both places.

Add a fourth rule only after the mistake has happened twice, or once at a cost you would not pay again.
